# Security Policy

## Verifying Downloads

Every release includes a `SHA256SUMS.txt` generated by the release workflow,
and the checksum is printed in the release notes.

### Verify with PowerShell

```powershell
(Get-FileHash -Path "WingetUpgradeManager.exe" -Algorithm SHA256).Hash
```

Compare the output against `SHA256SUMS.txt` or the release notes.

### Verify build provenance

Releases carry a GitHub build provenance attestation proving the exe was
built by this repository's CI from a specific commit:

```powershell
gh attestation verify WingetUpgradeManager.exe --owner Dsgj
```

## Why This Project is Safe

- **100% Open Source** — All code is visible and auditable
- **No Telemetry** — Zero data collection
- **No Network Requests of Its Own** — The app only runs local `winget`
  commands; all downloads are performed by winget itself
- **Automated Builds** — Release executables are built on GitHub's
  infrastructure by [release.yml](.github/workflows/release.yml)
- **Buildable from Source** — Build your own exe with `python build.py`
  (byte-identical builds are not guaranteed; use the attestation above to
  verify provenance instead)

## Build from Source

```powershell
git clone https://github.com/Dsgj/winget-upgrade-gui.git
cd winget-upgrade-gui
pip install -r requirements.txt -r requirements-dev.txt
python build.py
```

## Reporting Vulnerabilities

Please report security issues privately via GitHub's security advisory feature
([Security → Advisories → Report a vulnerability](https://github.com/Dsgj/winget-upgrade-gui/security/advisories/new))
rather than opening a public issue.
